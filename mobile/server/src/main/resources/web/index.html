Versão publicada

Instalar pelo StageNow

O StageNow baixa por HTTP — não por pasta de rede. Use este endereço no perfil:

  1. No StageNow (PC), crie um perfil e adicione o Wi-Fi do CD.
  2. Acrescente FileMgr → Transfer/Copy File, protocolo HTTP, com o endereço acima. Destino: /sdcard/Download/.
  3. Acrescente AppMgr → Install apontando para o arquivo baixado.
  4. Gere o QR pelo StageNow, imprima e leia com o cliente StageNow do coletor.

O QR do StageNow é gerado pela ferramenta da Zebra, não por este sistema — o formato é proprietário. Nosso papel é hospedar o APK num endereço fixo.

Relatório de separação

Baixar NF expedida

Marque as notas carregadas. Elas saem do estoque e os endereços ficam livres.

Retorno de mercadoria

Carga que saiu e o cliente não recebeu — recusou tudo (atraso na entrega, por exemplo) ou alguns pallets voltaram para reentrega. São três passos: registrar aqui os pallets que voltaram; o coletor confere caixa a caixa contra o que cada pallet levou; depois a tratativa — reentregar, refaturar ou descartar. Enquanto o retorno está aberto a NF sai das prontas para expedir. Os pallets voltam sem endereço (a posição antiga já foi reaproveitada) e entram na fila de endereçamento do coletor. Cliente que recebeu e devolveu parte da carga é devolução, não retorno.

Juntar / repaletizar

Bipe o pallet de origem, o de destino e depois as caixas que vão passar, uma a uma. Só entre pallets da mesma NF — ou para um pallet novo, ainda sem caixa, que passa a ser da NF da origem.

Bipe a origem e o destino: todas as caixas da origem vão para o destino, a origem sai de circulação e o cartão do destino é reimpresso. Só entre pallets da mesma NF (ou destino novo, ainda sem caixa).

    Conteúdo do pallet — transferir por quantidade

    Abra um pallet para transferir caixas, por quantidade, para um pallet novo que o sistema cria (dividir pallet alto demais, isolar avaria, separar carga de veículos diferentes) ou excluir caixas bipadas por engano. Transferir não muda a quantidade separada; excluir muda. Para passar caixa a caixa bipando, ou juntar dois pallets, use Juntar / repaletizar, acima.

    Endereços

    Cadastro em lote pela planilha

    Baixe o modelo (ou o cadastro atual, para corrigir), preencha no Excel e suba. Antes de gravar, a tela mostra linha a linha o que vai mudar.

    Subir e gravar a planilha é com o administrador.

    • Colunas do modelo: Depósito (código), Depósito (nome), Rua, Box, Código de barras (em branco = o próprio box), Tipo (ESTOCAGEM ou PICKING), Níveis (1 a 20) e Ativo (SIM ou NÃO).
    • Box que não está na planilha não é apagado: a planilha acrescenta e corrige.
    • Reduzir níveis só vale se o nível retirado nunca teve pallet. Desativar box com pallet endereçado é recusado.
    • Gravar é tudo ou nada: com qualquer linha com erro, nada muda.

    Desembarque

    A carreta é descarregada de uma vez: o pallet é montado aqui, por quantidade, em vez de caixa a caixa no coletor. O nome escolhido é quem desembarcou — é ele que aparece em Montado por, no Estoque.

    Ao iniciar, o sistema cria o pallet e manda a etiqueta para a impressora.

    ItemProdutoNFJá lançado Neste pallet

    O número é o total deste pallet, não o acréscimo: digitar 8 onde havia 10 tira duas caixas. O máximo de cada linha é o que ainda falta na NF.

    Estornar a baixa

    A mercadoria volta ao estoque: os pallets saem de expedidos e retomam o endereço, se a posição ainda estiver livre — senão voltam sem endereço, para o coletor endereçar de novo. Caixa que já tinha saído na baixa por caixa não volta.

    Excluir caixas separadas

    Reduz a quantidade separada e reabre o cadeado se estava fechado. É para caixa bipada por engano — para mudar caixa de pallet, use a repaletização.

    Excluir caixas separadas

    Isto reduz a quantidade separada — use só para caixa bipada por engano. Para mover caixa de pallet, use Transferir.
